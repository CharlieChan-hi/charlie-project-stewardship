# AI Project Context

## Summary

This plugin is a thin meta-harness for modern coding agents. It gives the model durable project
facts, safe deterministic utilities, and proportionate completion evidence while preserving the
model's freedom to reason, choose tools, and adapt its implementation path.

## Current Scope

- Inspect an existing or new repository and add only stewardship material that has demonstrated
  value there.
- Persist verified preferences, decisions, invariants, and failure memories with provenance,
  scope, detection, and refresh conditions.
- Relay long-running plans across machines or Agents with stable step identity and safe writes.
- Separate governance coverage from code-health signals and choose verification from the actual
  change surface.
- Offer source recipes as explicit, non-overwriting options.
- Detect real host capabilities before suggesting browsers, semantic indexes, task databases, or
  output compression.

## Non-Goals

- It is not a mandatory project operating system or a replacement for the host Agent.
- It does not require a fixed planning/TDD/review chain for every task.
- It does not score projects by how many plugin-specific documents they generated.
- It does not install optional integrations, publish, push, deploy, or change permissions by
  implication.
- It does not replace project-specific architecture, product, security, or design judgment.

## Model Compatibility

The package does not hard-code a model ID or API shape. Its outcome-first instructions, compact
autonomy boundary, progressive disclosure, and executable feedback loops are designed for current
Codex agents, including GPT-5.6 Sol-style reasoning. Compatibility is validated by behavior and
tool contracts rather than by assuming a particular model will follow a fixed script.

## Success Signals

- Relevant tasks complete without missing optional documents causing a stop.
- Safe local work does not trigger redundant approval questions.
- External or high-impact actions still stop at the correct approval boundary.
- Memory remains deduplicated, evidenced, scoped, and refreshable.
- Verification is relevant to the change, and unverified claims are explicit.
- Skill-trigger and invoked-context cost stays proportional to actual use.
