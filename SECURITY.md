# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/CharlieChan-hi/charlie-project-stewardship/security/advisories/new). Do not open a public issue for an unpatched vulnerability, and never include real credentials, secrets, or private repository contents in a report.

Include the affected version, operating system, reproduction steps using synthetic data, expected impact, and any relevant boundary such as symlink handling, path containment, atomic writes, secret redaction, or authorization behavior.

## Supported versions

Security fixes target the latest `2.x` release. Older releases may be asked to upgrade before a report is reproduced.

This project is local software and does not operate a hosted service. Reports about OpenAI, Codex, GitHub, Python, or another upstream product should be sent to that product's security channel unless the issue is caused by this repository's code or packaging.
